The following section describes the role model of scrumlr.
On a board there can be three types of users:

- Owner: the user how created the board
- Moderator: users how are promoted and moderate the board
- Participants: normal user

There can only be one owner on each board.

## Board settings

| Setting | Owner | Moderator | Participant |
| ------- | :---: | :-------: | :---------: |
| Change access settings | ✅ | ❌ | ❌ |
| Accept user session requests | ✅ | ✅ | ❌ |
| Promote participant to moderator | ✅ | ✅ | ❌ |
| Demote moderator to participant | ✅ | ✅ | ❌ |
| Ban participant from board | ✅ | ✅ | ❌ |
| Change board name | ✅ | ❌ | ❌ |
| Delete board | ✅ | ❌ | ❌ |
| Lock board | ✅ | ✅ | ❌ |
